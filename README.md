## Overview

This is a dual-file interactive reference tool providing side-by-side regulatory guidance for IRB approval criteria under:

- **45 CFR 46.111** — The Common Rule (OHRP)
- **21 CFR 56.111** — FDA Human Subjects Regulations

Each file is a self-contained HTML application. Together they form a companion pair, with cross-links in each header for easy navigation between the two regulatory frameworks. Both files integrate references to the Belmont Principles (Respect for Persons, Beneficence, Justice) to ground each approval criterion in its underlying ethical basis.

Designed for IRB reviewers, research administrators, compliance professionals, and training programs working at the intersection of AI, digital health technologies, and human subjects research.

## Deployment

To deploy on GitHub Pages:

1. Create a new repository (e.g., `irb-approval-criteria-reference`)
2. Upload both HTML files to the root of the repository
3. Go to **Settings → Pages**, set source to `main` branch, root folder
4. Both files will be live at:
   - `https://etotamiko-lab.github.io/Applying-Ethics-and-111s/46-111-irb-reference.html`
   - `https://etotamiko-lab.github.io/Applying-Ethics-and-111s/56-111-irb-reference.html`

The companion links in each file's header will work automatically as long as both files are in the same folder.
